# Multilevel-mediation-missingness

This GitHub repository contains the R code to reproduce the simulation studies presented in the paper:

**"A Causal Framework for Evaluating the Total Effect of Strategies Aiming to Expand Screening and to Improve Outcomes"**

by Joy Z. Nakato, Janice Litunya, Brian Beesiga, Jane Kabami, James Ayieko, Moses R. Kamya, Gabriel Chamie, and Laura B. Balzer.

*Statistics in Medicine* (2026), 45(15–17), e70648.

**Published paper:** https://doi.org/10.1002/sim.70648

**Preprint:** https://arxiv.org/abs/2506.06267

### Overview

This work introduces a causal framework for evaluating the total effects of interventions that aim to expand health screening and improve outcomes among an underlying target population whose membership may be incompletely observed.

Motivated by the OPAL cluster randomized trial in Kenya and Uganda, we define the causal estimand using **Counterfactual Strata Effects** and propose a novel extension of **Two-Stage Targeted Minimum Loss-Based Estimation (TMLE)** to address the challenges of multilevel data, mediation, and missingness.

The simulation studies evaluate the finite-sample performance of the proposed approach and compare it with alternative estimation strategies.
